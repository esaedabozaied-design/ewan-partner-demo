# إيوان للمطابخ والخزائن — منصة شركاء التطوير العقاري وتجربة اختيار المطبخ عبر QR

واجهة تفاعلية مخصصة لشركاء التطوير العقاري ومشتري الوحدات السكنية:
- **الرابط المباشر (GitHub Pages):** https://esaedabozaied-design.github.io/ewan-partner-demo/
- **إنفوجراف رحلة الـ QR للمطور العقاري:** https://esaedabozaied-design.github.io/ewan-partner-demo/infographic.html

## المزايا الرئيسية
1. **ربط التجربة بنموذج الشقة الفعلي:** اختيار بين 3 نماذج وحدات سكنية (`نموذج الشقة A`، `نموذج الشقة B`، `نموذج التاون هاوس C`) مع تحديث فوري للمخطط الهندسي العلوي (`2D Floorplan`) والأبعاد والمساحة.
2. **ثلاث باقات سهلة المقارنة (`A / B / C`):** جميعها بهيكل داخلي كامل من ألواح `PVC Foam Board` المقاومة للماء والرطوبة وضمان 10 سنوات مكتوب.
3. **استوديو تغيير الألوان والخامات التفاعلي:** تبديل فوري بين **6 ألوان وتشطيبات للواجهات** + **3 أسطح عمل** + **3 إضافات تنظيم داخلي (الكبينة المفتوحة)**.
4. **سعر مفهوم وشفاف + استكمال الطلب بسهولة:** حساب فوري للتجهيز والنقل وضريبة القيمة المضافة، مع حفظ الاختيارات في الرابط (`#hash`) وإرسالها كاملة عبر واتساب لفريق مبيعات إيوان أو طباعتها كملف PDF.
5. **إنفوجراف المطور العقاري ولوحة القياس:** شرح متكامل لرحلة الـ QR من 6 خطوات، توزيع المهام بين المطور وإيوان، ولوحة مؤشرات الأداء القابلة للقياس.
